Notes

• Type codes: 100 Standard, 102 Product Code, 111 Variable Info, 112 Additional Info, 130/131 EMV Data (request/response), 134 Transaction Attributes, 135/136 Moneris Data (request/response).
• Grouped elements (bold) contain the indented sub-fields beneath them — e.g. PromptCode → TransactionType, CardType and ProductTableEntry → ProductCode, UnitOfMeasure, Quantity, UnitPrice, ProductAmount.
• VarInfoTable_/AddlInfoTable_ numbers are table field IDs carried in the variable / additional-info segments.
• The Merchant Response body also carries message-level fields (ResponseCode, ApprovedAmount, DeclineCode, AuthorizerCode, AuthorizerRespCode, SettlementDate…) that sit outside any segment and are therefore not listed above.
