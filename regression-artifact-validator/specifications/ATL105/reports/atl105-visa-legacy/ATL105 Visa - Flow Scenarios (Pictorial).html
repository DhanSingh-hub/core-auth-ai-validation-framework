How to read this

• Each card is one distinct transaction flow; boxes are the ordered steps (transaction messages), read left → right.
• Badges show the number of test cases exercising the flow and their pass/fail split (green=all pass, amber=mixed, red=all fail).
• In the source report each step is usually its own TC row (trailing ID digit 0/1/2 = step index); the example TC IDs are members of the flow.
• Steps and chains are derived from TC descriptions by keyword rules; see the companion ATL105_Visa_flow_analysis.csv for the full per-TC data.
