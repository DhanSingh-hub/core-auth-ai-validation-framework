# Segment 145 Companion-Segment Compatibility: SME and TBA Note

## What Is Known

- Segment 145 must NOT co-occur with Segment 101 (Fleet Data Segment) in the same message.
- Segment 145 pairs with Segment 146 (Enhanced Fleet Response) in the response.

## What Not To Assume

- Do not assume Segment 145 can combine with Segment 101 under any circumstance — this is an explicit specification prohibition, not a mere recommendation to avoid.
