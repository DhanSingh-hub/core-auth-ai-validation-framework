# Secure Transport Rule Catalog

> Every rule learned from the 13 Secure Transport documents, one row per source statement, deduplicated within each document.
> Scope `GENERIC` means the generic guides (ST-UNIX-API, ST-XML-API); `RAPID_CONNECT` means the Rapid Connect package. Rapid Connect values never apply to BUYPASS without SME confirmation.
> Every rule is `PROVISIONAL` and outside certified ATL105 coverage. Applicability, precedence, scenarios, conflicts and SME queries are in the training record: [SecureTransport-Training-Knowledge.md](../../../test-validation-strategy/SecureTransport-Training-Knowledge.md).
> Quotations are verbatim and sit on the cited page, phase or lines; `scripts/verify-secure-transport-ingestion.py` checks this against the local sources.

Rules are grouped by family and then by topic, so statements of the same subject from different documents sit next to each other. Citations use `DOC-ID p.N` for PDF pages, `DOC-ID §seq` for Word phases and `DOC-ID lines N-M` for the schema and READ_ME files.
