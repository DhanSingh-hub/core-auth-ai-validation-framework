# Segment 119 Card-Bucket Totals: SME/TBA Note

## Repeated Data Model

Fields 17-19 form repeated card buckets:

```text
Card Label
  -> Card Type Total Count
  -> Card Type Total Amount
  -> next documented card label
```

The sequence is defined by the ATL105 card-label order. It is not an arbitrary list or a sorted list generated by the client.

## Presence Rules

- Card types 1-15 are included in all approved responses.
- Card types 16-20 are included only when data occurs.
- Up to 20 occurrences are supported.
- Non-financial categories marked with `*` do not contribute dollar amounts to Grand Total.

## Reconciliation Boundary

The spec identifies Grand Total and card-bucket amounts but does not provide a complete merchant reconciliation algorithm for every operational case. `SEG119-R-033` remains review-gated until the aggregation policy is approved.

## Test Pattern

- valid buckets in source-defined order;
- missing required bucket 1-15;
- out-of-order labels;
- duplicate label;
- unexpected bucket 16-20 with no data;
- non-financial amount incorrectly included in Grand Total.
