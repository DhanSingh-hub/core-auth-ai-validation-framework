Chapter 13.2, Element 113, PDF page 426 (printed page 13-86):
When Element No. 111 (Variable Information Indicator) has a value of 082 (Incremental Auth Data), the Incremental Auth Data is included here.

N2 Fixed Value: 82
N3 Fixed Length : 004
Terminal Transaction Number
N4 Used for tracking partial reversals and incomplete authorizations.
The Terminal Transaction Number should be unique for each Original Auth (aka Estimated Auth).
The Terminal Transaction Number should be the same value for all subsequent transactions tied to this original transaction (Incremental Auths, Partial or Full Reversals, IA Completions).
Therefore, when using the same card for Incremental Auth, the Terminal Transaction Number should be the same until the Incremental Auth series is completed.
Discover: Mandatory for Original/Estimated Auth and all the subsequent transactions.
Visa, MasterCard, Amex: This is optional, though highly encouraged to be populated along with Visa/MC/Amex Incremental Auth Lodging Data in Variable Information Segment 111 table ID 063.
Note: <Remaining bytes> are reserved for future use.
