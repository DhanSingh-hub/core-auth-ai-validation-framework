# AI Solution Input Artifacts

This folder is the intake area for artifacts generated by the AI Solution Team. These files are candidate inputs to the independent Test Validation framework; they are not approved Test Team outputs.

## Folder Structure

```text
test-input/ai-solution/
  manifest.json
  business-requirements/
  test-scenarios/
  test-cases/
  test-data/
  metadata/
  traceability/
  schemas/
```

## Artifact Locations

- `business-requirements/` - AI-generated business requirements JSON
- `test-scenarios/` - AI-generated test scenarios JSON
- `test-cases/` - AI-generated test cases JSON
- `test-data/` - AI-generated JSON test data files
- `metadata/` - format definitions, generation metadata, assumptions, and limitations
- `traceability/` - AI-provided traceability maps; the validator independently verifies them
- `schemas/` - JSON Schemas and format-version definitions supplied by the AI Solution Team
- `manifest.json` - package identity, specification version, producer, and package version

## Intake Rules

1. Preserve the original AI files exactly as received.
2. Do not edit AI artifacts in place to make validation pass.
3. Record the producer, package version, schema version, and generation timestamp.
4. Keep each AI package in its own versioned subfolder when multiple packages are received.
5. Test Validation reports belong under `test-output/`, not here.

## Validation Flow

```text
AI Solution files
  -> test-input/ai-solution/
  -> format/schema detection
  -> canonical normalization
  -> traceability and semantic validation
  -> coverage analysis
  -> test-output/ reports
```
