How to read the value map

• value×N means that value appeared in N of the segment occurrences. Values are sorted most-frequent first.
• K distinct values marks high-variability fields (PANs, sequence numbers, amounts, track/EMV/Moneris data); the top 3 values are shown as samples.
• · characters are the report’s fixed-width padding/filler; (blank) is an empty field.
• Header fields SegmentType / SegmentLength are greyed; grouped parents (PromptCode, ProductTableEntry) are bold with their sub-fields indented.
